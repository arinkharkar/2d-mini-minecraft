# 2D Minecraft

A little Java block game. Open the folder as an existing project in Eclipse and run Game.java. Java 8 or newer is needed.

You can also compile and run it from a terminal:

    javac -d bin src/Game.java
    java -cp bin Game

A/D or arrow keys move, Space jumps. Left click mines and right click places a block within reach. Pick a block with 1-9, or 0 for planks. Press C for crafting, then click a recipe or press P for planks, S for sticks, or K for a pickaxe. Recipes show the materials you have and whether you can craft them. A pickaxe is needed to mine iron and diamonds. Bedrock cannot be mined. Water is generated in low areas. Each launch makes a new world.
